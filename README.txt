# DZ Soluciones Integrales

## Estructura
- index.html → Inicio
- servicios.html → Servicios
- experiencia.html → Experiencia
- nosotros.html → Nosotros
- contacto.html → Presupuesto / contacto
- css/style.css → Diseño general
- js/script.js → Menú móvil y animaciones
- img/logo.png → Logo
- img/banner.png → Banner

## GitHub
Subí toda la carpeta manteniendo la estructura.
No cambies los nombres de las carpetas `css`, `js` e `img`.

## Importante
El formulario mantiene el correo y la configuración que estaban en la página original.
